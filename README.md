# Калькулятор

Консольная программа-калькулятор на Python 3.

## Возможности
- **Интерактивное меню:** Удобная навигация без перезапуска программы после каждого вычисления.
- **Базовые и расширенные операции:** Сложение, вычитание, умножение, деление, возведение в степень (`**`), извлечение квадратного корня (`sqrt`) вычисление остатка от деления (`%`).
- **Модульная архитектура:** Чёткое разделение на интерфейс (`main.py`), математическую логику (`calc_logic.py`) и управление данными (`db_manager.py`).
- **Постоянное хранение данных:** Автоматическая фиксация логов вычислений во встроенную базу данных SQLite (`history.db`).
- **Управление историей:** Просмотр последних 10 записей прямо из меню приложения или полная очистка таблицы данных.
- **Статистический модуль:** Вывод общего количества операций, среднего, максимального и минимального значений результатов.
- **Полнотекстовый поиск:** Возможность быстро найти записи в истории по числовому значению или знаку операции.
- **Отказоустойчивость:** Безопасный перехват пользовательских ошибок ввода (букв), деления на ноль и извлечения корня из отрицательного числа.

## Требования
- Python 3.10+
- ОС РЕДОС (или другой Linux)

## Установка и запуск

Проект снабжен автоматическими скриптами для быстрой настройки и запуска в Unix-среде:

1. **Клонируйте репозиторий** (или скопируйте папку с проектом).
2. **Сделайте скрипты исполняемыми** (выполняется один раз):
   ```bash
   chmod +x install.sh run.sh run_tests.sh
   ```
3. **Установите окружение и зависимости:**
   Скрипт автоматически создаст виртуальное окружение `venv`, обновит менеджер пакетов `pip`, установит все библиотеки из `requirements.txt` и инициализирует базу данных:
   ```bash
   ./install.sh
   ```
4. **Запустите калькулятор:**
   Скрипт автоматически активирует окружение, проверит зависимости и откроет интерактивное меню приложения:
   ```bash
   ./run.sh
   ```

## Тестирование

Для проверки корректности работы математических модулей и базы данных в проекте написаны Unit-тесты на фреймворке `pytest`.

Запуск тестов осуществляется одной командой с помощью автоматического скрипта:
```bash
./test.sh
```

### Что проверяют тесты:
* **calc_logic.py (Модульные тесты):** Проверка всех математических функций (сложение, вычитание, умножение, деление, остаток от деления), включая корректность округлений вещественных чисел и обработку исключений (деление на ноль).
* **db_manager.py (Интеграционные тесты):** Проверка сохранения одиночных и множественных записей в БД, корректность очистки истории вычислений, а также соблюдение лимитов вывода строк. Перед каждым тестом автоматически создается изолированная тестовая база данных `test_history.db`, которая удаляется после завершения проверок.

## Алгоритм работы

Ниже представлена блок-схема основной логики калькулятора:

```mermaid
graph TD
    A[Старт приложения] --> B[Инициализация БД: db_manager.init_db]
    B --> C[Отображение Главного меню]
    C --> D[Ввод действия пользователя: 1, 2, 3, 4, 5, 0]
    
    %% Ветка 2: История
    D -->|Выбор 2| H[Вызов show_history]
    H --> I[Чтение последних 10 записей из БД]
    I --> C
    
    %% Ветка 3: Очистка
    D -->|Выбор 3| J[Вызов db_manager.clear_history]
    J --> K[Удаление всех записей из таблицы]
    K --> C
    
    %% Ветка 4: Статистика
    D -->|Выбор 4| L1[Вызов show_statistics]
    L1 --> L2[Расчет COUNT, AVG, MAX, MIN через db_manager]
    L2 --> C
    
    %% Ветка 5: Поиск
    D -->|Выбор 5| M1[Вызов execute_search]
    M1 --> M2[Фильтрация записей в БД по LIKE keyword]
    M2 --> C
    
    %% Ветка ошибки ввода меню
    D -->|Неверный выбор| N[Вывод: Неверный выбор. Попробуйте снова]
    N --> C
    
    %% Ветка 0: Выход
    D -->|Выбор 0| L[Вывод: До свидания!]
    L --> M[Конец]
    
    %% Ветка 1: Вычисления
    D -->|Выбор 1| E[Вызов perform_calculation]
    E --> O{Какая операция?}
    
    O -->|sqrt| P[Ввод одного числа]
    O -->|+, -, *, /, **, %| Q[Ввод двух чисел]
    
    P --> R{Число < 0?}
    R -- Да --> S[Вывод: Ошибка корня из отрицательного]
    R -- Нет --> T[Вычисление: calc_logic.square_root]
    
    Q --> U{Операция / или % и второе число == 0?}
    U -- Да --> V[Вывод: Ошибка деления на 0]
    U -- Нет --> W[Вычисление: через calc_logic]
    
    S --> X[Возврат в Главное меню]
    V --> X
    
    T --> Y[Сохранение в БД и Вывод результата]
    W --> Y
    Y --> X
    X --> C
```
