# Калькулятор

Консольная программа-калькулятор на Python 3.

## Возможности
- Сложение, вычитание, умножение, деление
- Обработка ошибок ввода
- Обработка деления на ноль

## Требования
- Python 3.10+
- ОС РЕДОС (или другой Linux)

## Установка и запуск

1. Клонируйте репозиторий (или скопируйте папку)
2. Создайте виртуальное окружение:
   ```bash
   python3 -m venv venv
   ```
3. Активируйте окружение:
   ```bash
   source venv/bin/activate
   ```
4. Запустите программу:
   ```bash
   python main.py
   ```

## Алгоритм работы

Ниже представлена блок-схема основной логики калькулятора:

```mermaid
graph TD
    A[Старт] --> B{Какая операция?}
    B -->|sqrt| C[Ввод одного числа]
    B -->|+, -, *, /, **| D[Ввод двух чисел]
    C --> E{Число < 0?}
    E -- Да --> F[Вывод: Ошибка корня из отрицательного]
    E -- Нет --> G[Вычисление через calc_logic.square_root]
    D --> H{Операция / и второе число == 0?}
    H -- Да --> I[Вывод: Ошибка деления на 0]
    H -- Нет --> J[Вычисление результата через calc_logic]
    F --> K[Конец]
    G --> L[Вывод результата]
    I --> K
    J --> L
    L --> K
```
