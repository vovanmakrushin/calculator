# Калькулятор

Консольная программа-калькулятор на Python 3.

## Возможности
- **Интерактивное меню:** Удобная навигация без перезапуска программы после каждого вычисления.
- **Базовые и расширенные операции:** Сложение, вычитание, умножение, деление, возведение в степень (`**`) и извлечение квадратного корня (`sqrt`).
- **Модульная архитектура:** Чёткое разделение на интерфейс (`main.py`), математическую логику (`calc_logic.py`) и управление данными (`db_manager.py`).
- **Постоянное хранение данных:** Автоматическая фиксация логов вычислений во встроенную базу данных SQLite (`history.db`).
- **Управление историей:** Просмотр последних 10 записей прямо из меню приложения или полная очистка таблицы данных.
- **Отказоустойчивость:** Безопасный перехват пользовательских ошибок ввода (букв), деления на ноль и извлечения корня из отрицательного числа.

## Требования
- Python 3.10+
- ОС РЕДОС (или другой Linux)

## Установка и запуск

1. Клонируйте репозиторий (или скопируйте папку)
2. Создайте виртуальное окружение:
   ```bash
   python3 -m venv venv
   ```
3. Активируйте окружение:
   ```bash
   source venv/bin/activate
   ```
4. Запустите программу:
   ```bash
   python main.py
   ```

## Алгоритм работы

Ниже представлена блок-схема основной логики калькулятора:

```mermaid
graph TD
    A[Старт приложения] --> B[Инициализация БД: db_manager.init_db]
    B --> C[Отображение Главного меню]
    C --> D[Ввод действия пользователя: 1, 2, 3, 0]
    
    %% Ветка 2: История
    D -->|Выбор 2| H[Вызов show_history]
    H --> I[Чтение последних 10 записей из БД]
    I --> C
    
    %% Ветка 3: Очистка
    D -->|Выбор 3| J[Вызов db_manager.clear_history]
    J --> K[Удаление всех записей из таблицы]
    K --> C
    
    %% Ветка ошибки ввода меню
    D -->|Неверный выбор| N[Вывод: Неверный выбор. Попробуйте снова]
    N --> C
    
    %% Ветка 0: Выход
    D -->|Выбор 0| L[Вывод: До свидания!]
    L --> M[Конец]
    
    %% Ветка 1: Вычисления (Интеграция вашей детальной схемы)
    D -->|Выбор 1| E[Вызов perform_calculation]
    E --> O{Какая операция?}
    
    O -->|sqrt| P[Ввод одного числа]
    O -->|+, -, *, /, **| Q[Ввод двух чисел]
    
    P --> R{Число < 0?}
    R -- Да --> S[Вывод: Ошибка корня из отрицательного]
    R -- Нет --> T[Вычисление: calc_logic.square_root]
    
    Q --> U{Операция / и второе число == 0?}
    U -- Да --> V[Вывод: Ошибка деления на 0]
    U -- Нет --> W[Вычисление: через calc_logic]
    
    S --> X[Возврат в Главное меню]
    V --> X
    
    T --> Y[Сохранение в БД и Вывод результата]
    W --> Y
    Y --> X
    X --> C
```
