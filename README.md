# Калькулятор

Консольная программа-калькулятор на Python 3.

## Возможности
- Сложение, вычитание, умножение, деление
- Обработка ошибок ввода
- Обработка деления на ноль

## Требования
- Python 3.10+
- ОС РЕДОС (или другой Linux)

## Установка и запуск

1. Клонируйте репозиторий (или скопируйте папку)
2. Создайте виртуальное окружение:
   ```bash
   python3 -m venv venv
   ```
3. Активируйте окружение:
   ```bash
   source venv/bin/activate
   ```
4. Запустите программу:
   ```bash
   python main.py
   ```

## Алгоритм работы

Ниже представлена блок-схема основной логики калькулятора:

```mermaid
graph TD
    A[Старт] --> B[Ввод первого числа]
    B --> C[Ввод второго числа]
    C --> D[Ввод операции: +, -, *, /, **]
    D --> E{Операция верна?}
    E -- Нет --> F[Вывод: Неподдерживаемая операция]
    F --> D
    E -- Да --> G{Операция / и второе число == 0?}
    G -- Да --> H[Вывод: Ошибка деления на 0]
    G -- Нет --> I[Вычисление результата через calc_logic]
    I --> J[Вывод результата]
    H --> K[Конец]
    J --> K
```
